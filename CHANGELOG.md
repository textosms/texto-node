# Changelog

All notable changes to `@textoau/sdk` are documented here. This project follows
[Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-01-01

### Added

- First public release.
- Typed client covering messaging, inbox, opt-outs, credits, accounts, users,
  access, API keys, numbers, webhooks and reporting.
- Typed error classes, timeouts, and automatic retries for idempotent requests.
- HMAC-SHA256 webhook signature verification helpers.
- ESM and CommonJS builds with TypeScript declarations.
